# The Smich — сайт студии

Продвижение и сайты под него: делаем сайт и приводим на него клиентов (Казахстан).
Имиджевый сайт: 10 полноэкранных секций (план — [docs/PLAN.md](docs/PLAN.md)), в конце —
контакты и форма заявки. Плюс визитки команды `/yarik/`, `/emir/` и коммерческое
предложение `/kp-kz/` (тенге) и `/kp-ru/` (рубли).

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # сборка в dist/ — эту папку выкладывают на хостинг
npm run preview   # посмотреть собранную версию
```

Заявки: скопируйте `.env.example` в `.env` и укажите `VITE_LEAD_ENDPOINT` — адрес,
принимающий POST с JSON (свой сервер, вебхук Make/Zapier и т.п.). Без него заявка
только выводится в консоль браузера.

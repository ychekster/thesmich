# The Smich — лендинг

Сайты-каталоги и интернет-магазины под ключ + продвижение (Казахстан).
Одна страница: главный экран, анкета из 8 вопросов, частые вопросы-карты, футер.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # сборка в dist/ — эту папку выкладывают на хостинг
npm run preview   # посмотреть собранную версию
```

Заявки: скопируйте `.env.example` в `.env` и укажите `VITE_LEAD_ENDPOINT` — адрес,
принимающий POST с JSON (свой сервер, вебхук Make/Zapier и т.п.). Без него заявка
только выводится в консоль браузера.

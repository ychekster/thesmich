# AGENTS.md — инструкции для ИИ-агентов (Claude, GPT, Codex и др.)

Имиджевый сайт студии **The Smich** (Казахстан): **продвижение — главное, сайт —
инструмент**. Делаем сайт и приводим на него клиентов; без привязки к отрасли
(концепция — `docs/PLAN.md`). Полноэкранные секции, в конце — контакты и форма заявки.
Стек: Vite + React 19 + TypeScript + CSS Modules + Web Animations API. Сервера пока нет.

## Сначала прочитай

1. `docs/PLAN.md` — **действующий план сайта** (секции, концепция, что убрано).
2. `docs/ARCHITECTURE.md` — структура, где что менять (таблица в конце).
3. Документ по теме правки:
   - тексты, контакты, бонусы → `docs/CONTENT.md`;
   - анимации, переходы, визитки → `docs/ANIMATIONS.md`.

Не читай весь `src/` подряд. Найди нужный файл по таблице «Где что менять»
в `docs/ARCHITECTURE.md` и открывай только его и то, что он импортирует.

## Команды

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck  # tsc --noEmit — обязателен перед коммитом
npm run build      # typecheck + сборка в dist/
```

## Как вносить правки

1. **Тексты — только в `src/content/`.** Не хардкодь строки в компонентах.
2. **Стили — в `*.module.css` рядом с компонентом.** Цвета и поля — токены из
   `src/styles/global.css` (`--text`, `--grey`, `--accent`, `--line`, `--x`…).
3. **Анимации — только `transform`/`opacity`, без анимированного `filter`.** Плавность —
   «идеально, ни одного фриза»; после правок главной — замер по
   `docs/ANIMATIONS.md` («Производительность»). Покадровое — мимо React-стейта.
4. **Эффекты наведения** — только при `finePointer()` и не при `reducedMotion()`.
5. **Мобильная версия**: брейкпоинт `max-width: 760px`; проверь, что ничего не ломается.
6. **Документация обновляется в том же изменении**, что и код: новый компонент,
   поле контента, правило анимации — допиши в соответствующий файл `docs/`.
   Держи таблицу «Где что менять» актуальной.
7. Перед коммитом — `npm run typecheck`. Коммиты небольшие, по одной задаче.

## Правило перехода между секциями (для ВСЕХ секций, без исключений)

Решение владельца (2026-11-15). Переход от старой секции к новой, вниз или вверх —
зеркально, одинаково для любой секции, в том числе будущих:

1. **Новая секция едет быстрее старой**: приходит на весь экран, старая сдвигается
   медленнее, а её фон слегка ужимается по высоте ровно по краю новой.
2. **Контент старой секции разбирается в обратном порядке** — её анимация
   появления проигрывается задом наперёд (последний пришедший уходит первым),
   синхронно с перелистыванием: перелистывание кончилось — контент разобран.
3. **Контент старой секции едет со скоростью новой секции, а не своего фона** —
   отрывается от отстающего фона и уходит вместе с новой, будто она его выталкивает.
4. **Контент новой секции собирается на ту же величину перелистывания** (зеркало п. 2).
**Обновление (2026-11-16): пп. 2 и 4 отключены** — владелец: «никаких анимаций
у элементов в секциях, всё статично». Контент не собирается и не разбирается,
не проявляется, не выезжает; у кнопок и ссылок нет плавных переходов при наведении.
Двигаются только сами секции (пп. 1, 3, 5) и колесо бонусов при прокрутке.
Флаг — `REVEAL` в `src/pager/engine.ts`; не включать без запроса.

5. Один жест запускает переход фиксированной длины, дальше он доигрывает сам
   (секция не идёт «за пальцем»). Жест назад посреди перехода разворачивает его
   с текущей точки.

Реализация — `src/pager/engine.ts`; элементы контента помечаются `r(i)` / `<Lines>`
из `src/pager/reveal.tsx`. Подробно — `docs/ANIMATIONS.md`.

## Решения владельца (не откатывать без запроса)

- Сайт **имиджевый, не лендинг** (`docs/PLAN.md`): без анкеты, частых вопросов,
  футера и лишних кнопок. Единственный призыв — «Оставить заявку».
- Дизайн главной — **макет Claude Design от владельца (2026-11-15)**: Montserrat +
  Bebas Neue (заголовок первого экрана), контейнер 1250px на 1920×1080, красные
  уголки-треугольники, кнопки-«таблетки» с обводкой. Масштаб — токен `--u`
  (`docs/ARCHITECTURE.md`). Анимации из макета не переносим — только наши (переход
  секций, сборка контента, колесо).
  Ориентир по плавности и анимациям — сайт студии Promotion.
- Акцентный цвет — **красный** (`--accent`, `#ed0644`).
- Фоны секций — однотонные, по макету: тёмный `#212121`, красный, светло-серые, белый.
- Главная — секции на весь экран без промежуточной прокрутки: один жест (колесо,
  тачпад, свайп) — следующая секция. Шапка висит сверху, контент на неё не заезжает.
- Бонусы — **колесо фортуны** (не лента CS:GO). Крутить можно бесконечно, в заявку
  уходит последний бонус.
- **Элементы в секциях статичны** (2026-11-16): без появления, растворения, выезда
  строк и анимаций наведения. Без расталкивания букв курсором и без WebGL.
- Визитки команды (`/yarik/`, `/emir/`) — по образцу владельца: вертикальные, лицо —
  фото и крупное имя, оборот — роль, QR, имя и контакты (см. `docs/CONTENT.md`).
  Наклон к курсору/пальцу, блик от неподвижного света, переворот без перелёта.
- «Карьера» (вакансии) — **без цифр и условий** (60% на сайте не называть — дешевит студию):
  только посыл «можно работать без опыта» и кнопка в личку (`docs/PLAN.md`).
- **Дизайн секций владелец переделывает сам** — не редизайнить по своей инициативе.
- Регион — Казахстан: тенге, Kaspi.kz, 2ГИС, Instagram/TikTok; без российских сносок.
  Работаем по Казахстану и России: для России — отдельное КП `/kp-ru/` в рублях.
- КП (`/kp-kz/`, `/kp-ru/`) — по макету владельца (2026-11-16), цены — только из макета.

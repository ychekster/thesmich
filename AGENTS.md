# AGENTS.md — инструкции для ИИ-агентов (Claude, GPT, Codex и др.)

Лендинг студии **The Smich** (Казахстан): сайты-каталоги и интернет-магазины под ключ
плюс продвижение. Цель страницы — анкета из 8 вопросов и заявка.
Стек: Vite + React 19 + TypeScript + CSS Modules + motion. Сервера пока нет.

## Сначала прочитай

1. `docs/ARCHITECTURE.md` — структура, экраны, где что менять (таблица в конце).
2. Документ по теме правки:
   - тексты, вопросы, контакты → `docs/CONTENT.md`;
   - анимации, буквы, карты → `docs/ANIMATIONS.md`.

Не читай весь `src/` подряд. Найди нужный файл по таблице «Где что менять»
в `docs/ARCHITECTURE.md` и открывай только его и то, что он импортирует.

## Команды

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck  # tsc --noEmit — обязателен перед коммитом
npm run build      # typecheck + сборка в dist/
```

## Как вносить правки

1. **Тексты — только в `src/content/`.** Не хардкодь строки в компонентах.
2. **Стили — в `*.module.css` рядом с компонентом.** Цвета и поля — токены из
   `src/styles/global.css` (`--text`, `--grey`, `--accent`, `--line`, `--x`…).
3. **Анимации — только `transform`/`opacity`.** Покадровое — мимо React-стейта
   (движок `WaveText/engine.ts` или motion values). Правила — в `docs/ANIMATIONS.md`.
4. **Эффекты наведения** — только при `finePointer()` и не при `reducedMotion()`.
5. **Мобильная версия**: брейкпоинт `max-width: 760px`; проверь, что ничего не ломается.
6. **Документация обновляется в том же изменении**, что и код: новый компонент,
   поле контента, правило анимации — допиши в соответствующий файл `docs/`.
   Держи таблицу «Где что менять» актуальной.
7. Перед коммитом — `npm run typecheck`. Коммиты небольшие, по одной задаче.

## Решения владельца (не откатывать без запроса)

- Дизайн: чёрный фон, Inter, крупная типографика в духе Apple; главный экран — по центру.
- Заголовки собираются из букв и расталкиваются курсором, с тенью при наезде строк.
- Частые вопросы — 4 игральные карты: только масть в углах, **без подписей**
  («нажмите», «ответ» и т.п.), наклон к курсору, натуральный блик от неподвижного
  света (не за курсором), переворот по клику без перелёта,
  можно открыть несколько карт.
- Фраза «приводим на него покупателей» — просто жирная, без всплывающих окон.
- Регион — Казахстан: тенге, Kaspi.kz, 2ГИС, Instagram/TikTok; без российских сносок.
- Анимации — плавные, «как в видеоролике», без рывков.

## Не трогать без запроса

- Порядок и `id` вопросов анкеты (ключи заявки).
- Контакты-заглушки в `src/content/site.ts` — заменяются только на данные владельца.

# Тексты и контент

Все тексты, которые видит посетитель, лежат в `src/content/`. Компоненты их только
отображают. Правка текста не должна требовать правки компонента.

Сейчас тексты секций — **заглушки каркаса**: владелец прорабатывает контент каждой
секции сам (`docs/PLAN.md`).

## site.ts — бренд и контакты

`brand`, `cta` (кнопка «Оставить заявку» в шапке и на первом экране), `contacts`
(телефон, почта, Telegram, Instagram, город), `privacyHref`.

**Контакты — заглушки** (помечены `TODO`). Политики конфиденциальности нет — по закону
РК о персональных данных она нужна, раз сайт собирает имя и телефон.

## home.ts — секции главной

По объекту на секцию: `hero`, `about`, `sites`, `channels`, `promo`, `partners`,
`contacts`. Общие поля: `eyebrow` (надзаголовок), `title` (**массив строк** — каждая
выезжает из-под своей маски; неразрывный пробел перед тире, чтобы оно не
переносилось одно), `lead` (вводный текст).

- `about.points`, `sites.items`, `channels.items`, `partners.steps` — списки; число
  элементов можно менять (сетки перестроятся; следите, чтобы влезало в экран).
- `promo.youtubeId` — ID ролика (`youtu.be/<ID>`). Пусто — заглушка «Ролик скоро
  появится». Плеер грузится только по нажатию.
- `partners` — вакансии: `points` (три тезиса), `cta` — кнопка в личку (Telegram из
  `site.ts`). **Цифры и условия (60%) не писать** — решение владельца, `docs/PLAN.md`.
- `contacts.form` — подписи формы, темы заявки (`topics`: `site`, `partner`),
  сообщения «отправлено» и об ошибке.

Регион — **Казахстан**: цены в тенге (₸), каналы — Google, Яндекс, Instagram, TikTok,
Kaspi.kz, 2ГИС. Российские реалии (рубли, VK, Ozon, сноска про Meta) не добавлять.

## wheel.ts — колесо фортуны

`BONUSES`: `short` (надпись на секторе, до ~14 знаков), `full` (текст в результате,
в форме и в заявке). Число бонусов любое (секторы делятся поровну), шансы равные.
Сейчас 8 бонусов — **заглушки, владельцу утвердить**. `wheelText` — заголовок и кнопки.

## Заявка (lib/lead.ts)

Поля: `topic` (тема словами), `name`, `contact`, `message`, `bonus` (последний бонус
колеса — только для темы «Нужен сайт»), `submittedAt`.

## team.ts — визитки команды

Страницы `/yarik/` и `/emir/` — электронные визитки. Задача: **доверие и связь**.
Дизайн — **ровно по образцу владельца** (вертикальная визитка):

- Лицо: фото во весь размер карты, поверх — имя и фамилия заглавными, крупно,
  белым, по центру. Без фото — тёмная матовая карта и имя.
- Оборот (светлый): сверху жирно строчными «сооснователь / студии the smich»
  (`cardText.roleLines`), по центру QR (vCard; камера предлагает сохранить контакт,
  нажатие по QR скачивает .vcf), внизу имя заглавными и контакты строками без
  подписей: Telegram, телефон, Instagram (если есть), почта — все нажимаются.

`TEAM` — по человеку: `name`, `surname`, `role`, `photo` (путь от `public/`, например
`/team/yarik.jpg`; вертикальное фото), `contacts`. Пустое поле не показывается.
`studio.bin` — БИН/ИИН: **пусто, пока нет ИП/ТОО — не выдумывать**.
